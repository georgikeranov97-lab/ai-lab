## Цел

Да направя същите заявки през AI SDK, да сравня няколко модела по качество, цена и скорост и да разбера как `temperature` влияе на отговорите.

## Как се пуска

```bash
pnpm tsx same-request.ts   # Упражнение 2
pnpm tsx compare.ts        # Упражнение 3
pnpm tsx temperature.ts    # Упражнение 4
```

Нужен е файл `.env` с `ANTHROPIC_API_KEY` и `GOOGLE_GENERATIVE_AI_API_KEY`.
